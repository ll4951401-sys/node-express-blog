# Express Blog Project

Веб-застосунок для створення та перегляду постів, побудований на Node.js, Express та EJS.

## Опис
Проєкт дозволяє додавати нові пости (з заголовком та автором) та переглядати список усіх раніше створених постів.

## Встановлення та запуск

1. Клонувати репозиторій або завантажити файли проєкту:
   ```bash
   git clone [https://github.com/ll4951401-sys/node-express-blog.git](https://github.com/ll4951401-sys/node-express-blog.git)
   npm install
   npm run dev
